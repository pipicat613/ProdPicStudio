# ProdPicStudio

> 一款轻量级的纯前端图片设计工具，无需安装任何依赖。适用于电商主图制作、社交媒体封面。
<details>
<summary>English</summary>
A lightweight, pure front-end image design tool with zero dependencies. Ideal for e-commerce main product images and social media covers.
</details>

## 功能特性 | Features

- **多功能** – 模板功能、图层管理、水印添加、模糊效果
- **数据备份** – 可导出设计数据和配置文件为 json 文件，方便数据迁移和备份
- **友好的视觉UI** – 界面简洁，新手友好
- **纯前端运行** – 不依赖后端服务，所有处理在本地完成，隐私安全
<details>
<summary>English</summary>
Multi-function – Templates, layer management, watermarking, blur effects
Data Backup – Export design data and configuration as JSON files for easy migration and backup
User‑friendly UI – Clean interface, beginner‑friendly
Pure Frontend – No backend dependencies; all processing is done locally, ensuring privacy and security
</details>

## 快速开始 | Quick Start

### 使用方式 | How to Use

**方案一：在线体验**  
直接访问 [ProdPic Studio](https://pi-prodpic.netlify.app/) 即可使用全部功能。

**方案二：本地直接打开**  
克隆或下载本项目，使用浏览器打开根目录下的 `index.html` 即可。

**方案三：部署到静态服务器**  
将整个项目目录部署到任意静态文件服务器，访问对应URL即可。
<details>
<summary>English</summary>
Option 1: Online Demo
Visit [ProdPic Studio](https://pi-prodpic.netlify.app/) to access all features directly.

Option 2: Open Locally
Clone or download this repository and open index.html in your browser.

Option 3: Deploy to a Static Server
Deploy the entire project directory to any static file server and access the corresponding URL.
</details>
